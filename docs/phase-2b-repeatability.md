# Phase 2B PatchCore repeatability engineering record

## Scope

Two identical non-benchmark runs were executed on 2026-08-28 using only the
official `can/train/good` and `can/validation/good` directories. No evaluation
split was configured. `test_public`, both private splits, private labels, and the
MVTec evaluation server were not accessed.

This record is engineering evidence about repeatability. It contains no anomaly
test metric, benchmark result, effectiveness claim, or benchmark timing.

## Measured comparison

The fitted float32 memory bank had shape 4,218×1,536. Its SHA-256 was identical
in both runs:

`8267e9990f1109a80a24cc52bbaa7cc24799a28b3c228c956d52d4ba6dc38dc7`

All 46 ordered validation-normal image scores were bitwise equal; the maximum
absolute difference was 0.0. All 46 stored processed-coordinate anomaly-map
files had matching SHA-256 values. The Phase 2B comparator recalculated the
approved highest-order-statistic image threshold and the highest order statistic
of per-image pixel maxima; both thresholds were exactly equal across runs with
absolute difference 0.0. The provisional empirical-quantile values emitted by
the reused Phase 2A smoke runner were not treated as benchmark thresholds.

Under this same machine, package environment, data, weight file, configuration,
and seed, the measured path was bitwise repeatable for every compared artifact.

## Limitations

- This is one category and one seed, chosen for an engineering check rather than
  performance evaluation.
- It does not establish equality across operating systems, GPUs, drivers,
  PyTorch builds, CUDA runtimes, or future dependency resolutions.
- The compared anomaly maps are the 256×256 processed-coordinate smoke outputs.
  Phase 2C must apply and test the frozen original-coordinate restoration before
  official evaluation/submission.
- Deterministic settings can expose unsupported operations later; a future
  failure must be recorded rather than bypassed.
- Between-seed variability is intentionally assessed by the full three-seed
  benchmark protocol, not by selecting a favorable seed.
